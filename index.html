Devis IA Travaux

Devis de rénovation à partir de notes de visite

Transforme des notes de visite en devis de rénovation chiffré. Le LLM propose les lignes depuis une bibliothèque de prix ; chiffrage, TVA et totaux sont calculés par du code testé.

  • Python
  • FastAPI
  • LLM tool calling
  • n8n
  • Docker
Détails techniques
  • Transforme des notes de visite en texte libre en devis de rénovation chiffré.
  • Le LLM propose les lignes à partir d'une bibliothèque de prix (codes, quantités, hypothèses de calcul explicites) mais ne fixe aucun prix : chiffrage, TVA, totaux et contrôles sont déterministes et testés.
  • Les points incertains sont signalés (à chiffrer, questions à poser), les quantités restent modifiables, et le devis s'exporte en CSV ou PDF ; appelable depuis n8n via une API REST.
  • Python, FastAPI, LLM tool calling, Automation, n8n, Pydantic, Docker, CI.

Geo Assistant

Agent IA pour données géospatiales

Répond en langage naturel sur des données géospatiales du Luxembourg. Le LLM sélectionne des outils GeoPandas sur liste blanche ; chaque réponse montre sa trace et ses résultats sur une carte.

  • FastAPI
  • GeoPandas
  • Leaflet
  • LLM tool calling
  • Docker
Détails techniques
  • Répond à des questions en langage naturel sur des données géospatiales : un LLM sélectionne des outils GeoPandas déterministes, sur liste blanche, sans jamais écrire de code ni inventer de chiffres ; chaque réponse renvoie la trace de ses appels d'outils et ses résultats sur une carte.
  • Données ouvertes réelles du Luxembourg (limites administratives, arrêts de transport public, écoles géocodées), calculs métriques en EPSG:2169.
  • FastAPI + Leaflet, couche LLM indépendante du fournisseur (API compatible OpenAI, testée avec gpt-oss-20b), jeu d'évaluation, tests, Docker, CI GitHub Actions ; déployé en ligne.

Démo en ligne GitHub

Geometry Assistant

Agent IA pour pièces 3D (Three.js)

Questions en langage naturel sur une pièce STL/OBJ. Le LLM sélectionne des outils trimesh sur liste blanche ; la visionneuse Three.js affiche faces, coupes et cotes.

  • Three.js
  • trimesh
  • FastAPI
  • LLM tool calling
  • Docker
Détails techniques
  • Chargement d'une pièce STL/OBJ et questions en langage naturel : le LLM sélectionne des outils trimesh sur liste blanche (volume, analyse des surplombs pour l'impression 3D, coupes, mesures) et ne calcule jamais la géométrie lui-même.
  • La visionneuse Three.js applique chaque résultat : faces surlignées, contours de coupe, cotes, mouvements de caméra ; rendu à la demande et sélection accélérée par BVH.
  • FastAPI, context engineering (modèle actif, points sélectionnés, vue), jeu d'évaluation, tests, Docker, CI GitHub Actions ; déployé en ligne.
